# S8.1 — Multi-Jira Support

## Description

Allow the application to connect to multiple Jira instances simultaneously.
Each connection has its own credentials, projects, and data isolation.

## Acceptance Criteria

- [ ] `JiraConnection` DB table: id, name, url, auth_type, credentials (encrypted), is_active
- [ ] `JiraClient` instantiated per connection from DB config
- [ ] `Project` linked to connection via `connection_id` FK
- [ ] Extraction runs per connection, isolated
- [ ] KPI results tagged with `connection_id`
- [ ] API to create/update/delete connections (admin only)
- [ ] Connection health check endpoint: `GET /api/admin/connections/{id}/health`
- [ ] Credentials encrypted at rest (AES-256-GCM with APP_SECRET_KEY)

## Implementation Notes

- Credential encryption: use `cryptography.fernet` or AES-GCM
- Connection pool: cache clients keyed by connection_id
- Extraction scheduler iterates over all active connections
- Data isolation: all queries filter by connection_id
