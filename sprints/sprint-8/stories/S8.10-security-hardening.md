# S8.10 — Security Hardening

## Description

Apply security hardening measures: HTTPS redirect, security headers,
rate limiting on auth endpoints, and input validation improvements.

## Acceptance Criteria

- [ ] HTTPS redirect middleware (if behind reverse proxy)
- [ ] Security headers on all responses:
  - `Strict-Transport-Security: max-age=31536000; includeSubDomains`
  - `Content-Security-Policy: default-src 'self'`
  - `X-Content-Type-Options: nosniff`
  - `X-Frame-Options: DENY`
  - `X-XSS-Protection: 1; mode=block`
  - `Referrer-Policy: strict-origin-when-cross-origin`
- [ ] Login endpoint rate-limited: 5 attempts per minute per IP
- [ ] Input validation: all string inputs sanitized (strip control chars)
- [ ] JSON body size limit: 1MB max per request
- [ ] API key rotation endpoint: `POST /api/admin/rotate-key`
- [ ] Security.txt file at `/.well-known/security.txt`

## Implementation Notes

- Security headers via FastAPI middleware
- Rate limiting on login endpoint via in-memory counter per IP
- Input sanitization via Pydantic validators

- `backend/main.py` — add security middleware, headers, rate limiting
