# S8.6 — Webhook Receiver

## Description

Create a webhook endpoint that receives Jira event notifications and
triggers incremental sync for affected issues in near-real-time.

## Acceptance Criteria

- [ ] `POST /api/webhooks/jira` receives Jira webhook payloads
- [ ] Supports event types: `jira:issue_created`, `jira:issue_updated`, `jira:issue_deleted`
- [ ] Webhook secret validation (HMAC-SHA256 signature check)
- [ ] Extracts issue key from payload and triggers incremental sync
- [ ] Sync completes within 30s of webhook receipt
- [ ] Failed webhooks retried up to 3 times with exponential backoff
- [ ] Webhook logged to audit log with event type and issue key
- [ ] Webhook configuration endpoint: `GET /api/admin/webhooks/setup`
- [ ] Returns Jira webhook URL and secret for easy configuration

## Implementation Notes

- Jira sends webhook payload as JSON with `X-Hub-Signature` header
- Validate signature using `config.WEBHOOK_SECRET`
- Incremental sync: re-extract the specific issue by key
- For `issue_deleted`: mark issue as deleted in DB (soft delete)
