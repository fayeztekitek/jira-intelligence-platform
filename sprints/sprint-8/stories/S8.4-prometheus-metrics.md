# S8.4 — Prometheus Metrics

## Description

Expose Prometheus metrics for monitoring: request count, latency,
error rate, API call count per endpoint, and sync job duration.

## Acceptance Criteria

- [ ] `/metrics` endpoint returning Prometheus-formatted text
- [ ] Metrics: `http_requests_total` by endpoint, method, status
- [ ] Metrics: `http_request_duration_seconds` histogram
- [ ] Metrics: `extraction_duration_seconds` by project
- [ ] Metrics: `extraction_errors_total` by project
- [ ] Metrics: `kpi_computation_duration_seconds` by project
- [ ] Metrics: `active_jira_connections` gauge
- [ ] Default metrics from `prometheus_client` (CPU, memory, GC)
- [ ] Middleware to track request metrics automatically

## Implementation Notes

- Use `prometheus_client` library
- Register `/metrics` endpoint before other routes
- Use `labels` to differentiate by endpoint, method, status
- Sync jobs use `Summary` or `Histogram` metric types
