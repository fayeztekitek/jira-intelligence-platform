# S8.5 — Admin Dashboard

## Description

Build a frontend admin dashboard for managing Jira connections, viewing
audit logs, and configuring system settings.

## Acceptance Criteria

- [ ] "Admin" tab visible only to admin users
- [ ] Connections management: add/edit/delete Jira connections
- [ ] Connection health status indicator (green/red)
- [ ] Audit log viewer: filterable table with date range, user, endpoint
- [ ] User management: list users, change roles, enable/disable
- [ ] System settings: KPI period defaults, export limits, retention
- [ ] Metrics overview: request rate, error rate, active users
- [ ] All mutations require admin role (checked server-side)

## Implementation Notes

- Admin API endpoints in a separate `api/admin.py` router
- Frontend uses same apiFetch() pattern as other pages
- Audit log table paginated (50 rows per page)
