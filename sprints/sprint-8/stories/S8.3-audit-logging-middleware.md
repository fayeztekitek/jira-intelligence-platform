# S8.3 — Audit Logging Middleware

## Description

Add middleware that logs all data-accessing API requests to an `audit_log`
table: timestamp, user, endpoint, method, project, and response status.

## Acceptance Criteria

- [ ] `AuditLog` table: id, timestamp, user_id, endpoint, method, project_id, status_code, duration_ms, ip_address
- [ ] Middleware logs every request to `/api/*` (except health/liveness)
- [ ] Authentication failures logged with user="anonymous"
- [ ] Admin can query audit logs via `GET /api/admin/audit-logs`
- [ ] Logs retained for 90 days (configurable)
- [ ] Logs queryable by: date range, user, endpoint, project
- [ ] Asynchronous logging (background task, not blocking request)

## Implementation Notes

- Use FastAPI `@app.middleware("http")` or `BaseHTTPMiddleware`
- Log via session.add() and commit in background task
- Background task via `BackgroundTasks` to avoid adding latency
