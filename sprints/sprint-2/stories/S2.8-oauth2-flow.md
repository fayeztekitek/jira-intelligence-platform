# S2.8 — OAuth2 Flow Implementation

## Description

Implement the OAuth2 authorization code flow for Jira Cloud, allowing users to
authenticate via Atlassian's OAuth2 provider instead of API tokens.

## Acceptance Criteria

- [ ] OAuth2 authorize URL endpoint (`GET /api/auth/jira/authorize`)
- [ ] OAuth2 callback handler (`GET /api/auth/jira/callback`)
- [ ] Token refresh mechanism (access + refresh tokens)
- [ ] Token stored securely (encrypted in DB or env)
- [ ] Client automatically refreshes expired tokens
- [ ] Supports multiple Jira instances (each with its own OAuth2 config)

## Implementation Notes

- Register app in Atlassian Developer Console
- `client_id` and `client_secret` from env vars
- Use httpx OAuth2 helpers or `atlassian-python-api`
- Scopes: `read:jira-work`, `offline_access`, `manage:jira-project`

- `backend/jira_connector/client.py` — add OAuth2 token refresh
- `backend/config.py` — add OAuth2 settings
