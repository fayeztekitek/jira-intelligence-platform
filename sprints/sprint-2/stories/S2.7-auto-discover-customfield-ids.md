# S2.7 — Auto-Discover Customfield IDs

## Description

Query `GET /rest/api/3/field` to discover all customfield IDs automatically,
mapping known names (`Epic Link`, `Story Points`, `Sprint`) to their IDs
for the connected Jira instance.

## Acceptance Criteria

- [ ] `GET /api/fields` endpoint returns discovered field mappings
- [ ] Auto-detect `epic_link`, `story_points`, `sprint` by name patterns
- [ ] Store mappings in a `FieldMapping` DB table (or in-memory cache)
- [ ] Override with env vars if set (env var takes precedence)
- [ ] Works for Jira Cloud (v3 API) and Jira Server (v2 API)

## Implementation Notes

- `GET /rest/api/3/field` returns all fields with `id`, `name`, `schema`
- Pattern match: `"Epic Link"` → `epic_link`, `"Story Points"` → `story_points`
- Store in a simple dict cache keyed by `jira_instance_url`
