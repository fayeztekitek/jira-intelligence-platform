# S2.6 — Populate lead_time_days and cycle_time_days

## Description

The `lead_time_days` and `cycle_time_days` columns on `FactIssue` were
never populated during extraction. Compute and store these values from
issue timestamps.

## Acceptance Criteria

- [x] `lead_time_days = resolved_date - created_date` (for resolved issues)
- [x] `cycle_time_days = resolved_date - in_progress_date` (from changelog)
- [x] NULL for unresolved issues
- [x] Values stored on `FactIssue` during upsert

## Implementation Notes

- `lead_time_days` computed from issue fields directly
- `cycle_time_days` requires changelog parsing for first "In Progress" transition
