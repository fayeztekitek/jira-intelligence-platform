# S2.9 — Extractor Unit Tests

## Description

Write comprehensive unit tests for the extraction layer covering:
full extraction, incremental extraction, upsert logic, error handling,
and edge cases.

## Acceptance Criteria

- [ ] `test_full_extraction` — extracts all issues for a project
- [ ] `test_incremental_extraction` — extracts only updated since last run
- [ ] `test_upsert_creates_new` — new issue inserted into DB
- [ ] `test_upsert_updates_existing` — existing issue fields updated
- [ ] `test_extraction_empty_project` — no issues, no crash
- [ ] `test_extraction_api_error` — retry on 429, fail on 500
- [ ] `test_changelog_extraction` — transitions parsed correctly
- [ ] `test_sprint_field_parsing` — sprint values extracted from customfield
- [ ] Mock Jira API responses with `httpx` and `respx`
