# S2.1 — Configurable Customfield IDs

## Description

Make Jira customfield IDs for `epic_link`, `story_points`, and `sprint`
configurable via environment variables instead of hardcoded values.

- [x] `JIRA_FIELD_EPIC_LINK`, `JIRA_FIELD_STORY_POINTS`, `JIRA_FIELD_SPRINT` env vars
- [x] Default values matching common Jira Cloud IDs (`customfield_10014`, etc.)

- [x] Extractor uses configurable field IDs to parse issue data
- [x] `.env.example` documents all three variables
