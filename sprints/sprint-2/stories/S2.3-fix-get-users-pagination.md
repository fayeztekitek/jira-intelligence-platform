# S2.3 — Fix get_users Pagination

## Description

The `get_users()` method was not handling pagination correctly, returning
only the first page of results (max 50 users) and missing all subsequent pages.

## Acceptance Criteria

- [x] `get_users()` iterates through all pages via `startAt` parameter
- [x] Handles empty pages gracefully (stops iteration)
- [x] Returns complete list of all users
- [x] Respects `maxResults` per page (default 50)

## Implementation Notes

- Use same pagination pattern as `_paginated_get()`
- Jira `/user/search` API uses `startAt` and `maxResults` params
