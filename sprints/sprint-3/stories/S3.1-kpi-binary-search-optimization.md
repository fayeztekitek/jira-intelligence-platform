# S3.1 — KPI Engine Binary Search Optimization

## Description

Replace the O(n) scan per period in the KPI calculator with a binary
search on pre-sorted date arrays. This reduces per-period cost from
O(n) to O(log n + k) where k is the number of items in the window.

## Acceptance Criteria

- [x] Dates sorted once, then binary-searched per period
- [x] All existing KPI families (delivery, quality, risk, team) work
- [x] Results match the old O(n) implementation exactly
- [x] Measured improvement: 10x+ faster for 10k+ issues

## Implementation Notes

- `_windowed_issues()` uses `bisect_left`/`bisect_right` on sorted `created`/`resolved` arrays
- Maintain a pre-sorted copy of issues per project at the start of `compute_project_kpis`
