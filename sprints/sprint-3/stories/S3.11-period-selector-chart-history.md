# S3.11 — Period Selector Affects Chart History

## Description

The period selector dropdown (1m, 3m, 6m, 1y) currently only affects the
KPI card values. Make it also control the date range shown in the history
charts (Created vs Resolved, Bug Trend, Risk Trend).

## Acceptance Criteria

- [ ] Period selector changes API query parameter for history endpoints
- [ ] Charts re-fetch and re-render with new range
- [ ] Current period highlighted in selector
- [ ] Smooth transition between periods (no flash)

## Implementation Notes

- Pass `period` parameter to all history API calls
- Adjust `days` parameter accordingly (1m=30, 3m=90, 6m=180, 1y=365)

## Files Changed

- `frontend/index.html` — period change handler updates chart queries
