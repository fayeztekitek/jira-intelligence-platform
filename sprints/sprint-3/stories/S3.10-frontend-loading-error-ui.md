# S3.10 — Frontend Loading & Error UI

## Description

Add loading spinners and error state displays to all chart and KPI card
components in the frontend. Currently charts show empty/blank during
loading and silently fail on API errors.

## Acceptance Criteria

- [ ] Loading spinner shown while API request is in flight
- [ ] Error message displayed on API failure (with retry button)
- [ ] Empty state shown when API returns no data
- [ ] All pages/views have consistent loading/error/empty UX
- [ ] Animations are subtle (CSS-only, no heavy libraries)

## Implementation Notes

- Use CSS-only spinner (border animation)
- Error state: red banner with message + "Retry" link
- Empty state: grey info card with icon

## Files Changed

- `frontend/index.html` — added loading/error/empty states to all chart components
