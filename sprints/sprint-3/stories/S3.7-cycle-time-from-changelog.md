# S3.7 — cycle_time_days from Changelog

## Description

Compute `cycle_time_days` by finding the first transition into an
"In Progress" status from the issue changelog, then subtracting from
the resolution date.

## Acceptance Criteria

- [ ] Changelog parsed for first "In Progress" status transition
- [ ] `cycle_time_days = resolved_date - first_in_progress_date`
- [ ] NULL if issue never entered "In Progress" or unresolved
- [ ] Stored on `FactIssue.cycle_time_days`
- [ ] Runs during incremental extraction (only new/updated issues)

## Implementation Notes

- Extract first transition with `field="status"` and `to_string` matching known "In Progress" statuses
- Jira allows custom status names — support configurable list via env var or auto-detect

## Files Changed

- `backend/ingestion/extractor.py` — compute cycle_time from changelog
- `backend/jira_connector/client.py` — ensure changelog fetched for all issues
