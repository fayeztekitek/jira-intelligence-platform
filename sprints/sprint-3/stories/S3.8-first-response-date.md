# S3.8 — first_response_date from Comments

## Description

Populate the `first_response_date` column on `FactIssue` by finding the
earliest comment from anyone other than the issue reporter.

## Acceptance Criteria

- [ ] Comments fetched for each issue (if not already loaded)
- [ ] `first_response_date` = created date of first non-reporter comment
- [ ] NULL if no comments from non-reporter
- [ ] Stored on `FactIssue.first_response_date`

## Implementation Notes

- Jira comment API: `/rest/api/3/issue/{key}/comment`
- Filter comments where `author.accountId != reporter.accountId`
- First response is an important SLA/quality metric

- `backend/ingestion/extractor.py` — fetch comments, set first_response_date
