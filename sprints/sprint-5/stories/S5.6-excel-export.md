# S5.6 — Excel Export

## Description

Add `.xlsx` export endpoint with separate sheets per KPI category plus an Issues sheet. Uses openpyxl for formatting.

## Acceptance Criteria

- [ ] `GET /api/export/xlsx?project_key=X` returns `.xlsx` file
- [ ] Sheets: Delivery KPIs, Quality KPIs, Risk KPIs, DQ KPIs, Team KPIs, Issues
- [ ] Headers are bold with colored backgrounds
- [ ] Column widths auto-sized
- [ ] Number cells formatted appropriately (percentages with %, decimals to 1 place)
- [ ] Response has correct Content-Type (`application/vnd.openxmlformats-officedocument.spreadsheetml.sheet`) and Content-Disposition

## Implementation Notes

- New file `api/export.py` for export logic
- Install `openpyxl` and add to `requirements.txt`
- KPI data from `KPIResult`, issues from `FactIssue`
- Use `openpyxl.Workbook()` with named sheets
