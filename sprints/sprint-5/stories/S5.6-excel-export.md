# S5.6 — Excel Export

## Description

Create `GET /api/export/xlsx` that generates an Excel workbook with
multiple sheets, one per KPI category, with formatted headers.

## Acceptance Criteria

- [ ] Sheets: Delivery KPIs, Quality KPIs, Risk KPIs, DQ KPIs, Team KPIs, Issues
- [ ] Formatted headers (bold, colored, frozen)
- [ ] Auto-sized columns
- [ ] Number formatting (percentages, decimals, dates)
- [ ] Color coding for risk values (green/yellow/red)
- [ ] File size limit: < 10MB for 50k rows
- [ ] Content-Disposition header with filename

## Implementation Notes

- Use `openpyxl` library
- Write to `BytesIO` buffer, stream via `StreamingResponse`
- Each sheet is a separate DB query
