# S5.8 — Export Button in Frontend

## Description

Add export buttons to the frontend that trigger CSV, Excel, and PDF
downloads from the backend export endpoints.

## Acceptance Criteria

- [ ] CSV Export button on Executive page (top right)
- [ ] Excel Export button on Executive page
- [ ] PDF Export button on Executive page
- [ ] Buttons show loading state during generation
- [ ] Download triggers browser file save dialog
- [ ] Filename includes date and project name

## Implementation Notes

- Use `window.open()` or `<a download>` for direct download
- Or `fetch()` → `Blob` → `URL.createObjectURL` for programmatic download
- Buttons disabled while export is generating
