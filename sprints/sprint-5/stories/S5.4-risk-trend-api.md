# S5.4 — Risk Trend API

## Description

Add endpoint `GET /api/projects/{key}/risk/history` returning daily composite risk + dimension scores for the last N days.

## Acceptance Criteria

- [ ] `GET /api/projects/{key}/risk/history?days=90&period=1m` returns ordered list of risk scores
- [ ] Each entry: `date`, `composite_risk`, `risk_level`, `delivery`, `quality`, `compliance`, `operational`
- [ ] Returns empty array if no data
- [ ] Default `days=90`, `period=1m`

## Implementation Notes

- Query `RiskScore` table filtered by project_key, ordered by `calculation_date`
- Filter by `period_label` column (add if not present in model)
- Add Alembic migration for `period_label` on `RiskScore`
