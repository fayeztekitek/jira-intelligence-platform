# S5.4 — Risk Trend API

## Description

Create `GET /api/risk/history` that returns a time series of composite
risk scores and individual dimension scores for the selected period.

## Acceptance Criteria

- [ ] Returns `[{date, composite, blocked, aging, ...}]` per day
- [ ] Accepts `days` parameter (default 90)
- [ ] Accepts `project_id` parameter (default all projects)
- [ ] Each entry has composite + dimension scores
- [ ] Cached for 1 hour (risk data is expensive to recompute)

## Implementation Notes

- Query `RiskScore` table grouped by date
- Composite = weighted sum of dimensions
- Use same `FactSnapshot` data if available (already computed daily)
