# S5.8 — Export Button in Frontend

## Description

Add an "Export" dropdown button to the frontend header/sidebar with options for CSV, Excel, and PDF export.

## Acceptance Criteria

- [ ] Export button with dropdown: CSV, Excel (.xlsx), PDF Report
- [ ] CSV export triggers download with current project filter
- [ ] Excel and PDF export with current project filter
- [ ] Loading indicator during export
- [ ] Error toast if export fails
- [ ] File names include project key and date (e.g. `CORE_issues_2026-06-26.csv`)

## Implementation Notes

- Use `<a href>` with `download` attribute for CSV (direct API call)
- For Excel/PDF use `window.open(apiUrl)` or fetch + blob download
- Add export button to the right of "Period" tabs or in sidebar footer
