# S5.3 — Configurable Risk Weights

## Description

Make risk dimension weights configurable via environment variable instead
of hardcoded values, allowing teams to tune risk scoring to their context.

## Acceptance Criteria

- [ ] `RISK_WEIGHT_BLOCKED`, `RISK_WEIGHT_AGING`, etc. env vars
- [ ] Weights normalized to sum to 1.0
- [ ] Defaults match current hardcoded values
- [ ] Invalid weights (non-numeric, negative) fall back to defaults
- [ ] Logged on startup for auditability

## Implementation Notes

- Parse JSON dict from env var: `{"blocked": 0.3, "aging": 0.3, ...}`
- Normalize: divide each weight by sum of all weights

## Files Changed

- `backend/config.py` — add RISK_WEIGHTS setting
- `backend/risk_engine/scorer.py` — use configurable weights
