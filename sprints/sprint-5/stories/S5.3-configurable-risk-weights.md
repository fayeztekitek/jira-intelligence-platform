# S5.3 — Configurable Risk Weights

## Description

Make risk scoring weights configurable via environment variable instead of hardcoded. Allow per-dimension weights (delivery, quality, compliance, operational).

## Acceptance Criteria

- [ ] New config setting `RISK_WEIGHTS` read from env var (JSON string or comma-separated)
- [ ] Default weights match current hardcoded values
- [ ] Weights validated at startup (must sum to ~1.0)
- [ ] Fallback to defaults if env var not set or invalid

## Implementation Notes

- In `config.py`: `risk_weights: dict[str, float] = field(default_factory=lambda: {"delivery": 0.35, "quality": 0.25, "compliance": 0.15, "operational": 0.25})`
- Parse from `RISK_WEIGHTS` env var as JSON
- Apply in `RiskScorer._compute_composite_risk()`
