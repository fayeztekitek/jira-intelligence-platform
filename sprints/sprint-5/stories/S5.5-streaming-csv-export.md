# S5.5 — Streaming CSV Export

## Description

Create `GET /api/export/csv` that streams a CSV file of all issues with
their KPI data, using FastAPI's `StreamingResponse` to handle large datasets.

## Acceptance Criteria

- [ ] Streaming CSV response (not buffered in memory)
- [ ] Configurable row limit via `max_rows` parameter (default 100k)
- [ ] Columns: issue key, summary, project, status, priority, created, resolved, lead_time, cycle_time, sprint, story_points, risk_score
- [ ] Proper CSV escaping (commas, quotes, newlines in fields)
- [ ] UTF-8 BOM for Excel compatibility
- [ ] Content-Disposition header with filename

## Implementation Notes

- Use `csv.writer` with `io.StringIO` in chunks
- Stream via `StreamingResponse` with `text/csv` media type
- Query in batches of 1000 to avoid memory pressure
