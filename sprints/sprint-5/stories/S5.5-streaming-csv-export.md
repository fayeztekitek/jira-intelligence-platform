# S5.5 — Streaming CSV Export

## Description

Replace the existing CSV export with a proper streaming implementation that handles large datasets without memory exhaustion. Add configurable row limit.

## Acceptance Criteria

- [ ] `GET /api/export/csv?project_key=X&max_rows=10000` streams CSV rows
- [ ] Configurable `max_rows` parameter (default 10k, max 100k)
- [ ] Uses `StreamingResponse` with async generator for true streaming
- [ ] Headers: Content-Disposition with filename, Content-Type text/csv
- [ ] Maintains existing column set + adds new columns (comments count, last comment date)
- [ ] Handles empty result set gracefully (returns headers only)

## Implementation Notes

- Use async generator that yields chunks of rows
- Keep column order consistent (Key, Summary, Type, Status, Priority, Assignee, Created, Resolved, Age, Resolution Time, Overdue, Reopened, DQ flags)
