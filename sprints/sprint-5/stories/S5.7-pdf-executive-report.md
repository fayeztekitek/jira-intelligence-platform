# S5.7 — PDF Executive Report

## Description

Create `GET /api/export/pdf` that generates an A4 PDF executive summary
report containing: risk matrix, KPI summary cards, alert list, and
project rankings.

## Acceptance Criteria

- [ ] A4 format, landscape for risk matrix, portrait for summary
- [ ] Executive summary section (top KPIs, trends)
- [ ] Risk matrix grid (Likelihood vs Impact)
- [ ] KPI cards with values and trend arrows
- [ ] Alert list: top 10 issues requiring attention
- [ ] Project ranking table by composite risk score
- [ ] Date and project name on every page
- [ ] Page numbers and table of contents

## Implementation Notes

- Use `weasyprint` with HTML+CSS template rendering
- Generate complete HTML with inline CSS, convert to PDF
- Template uses Jinja2 for dynamic data
