# S5.7 — PDF Executive Report

## Description

Generate a downloadable A4 PDF executive report with risk matrix, KPI summary cards, and alert list using weasyprint with HTML templates.

## Acceptance Criteria

- [ ] `GET /api/export/pdf?project_key=X` returns PDF file
- [ ] A4 format with proper margins and typography
- [ ] Title page with project name, generation date, overall health
- [ ] Risk matrix section with composite + dimension scores as cards
- [ ] KPI summary section with top 10 KPIs (name, value, trend, risk level)
- [ ] Alert list section with all active alerts
- [ ] Footer with page numbers and generation timestamp
- [ ] Content-Type `application/pdf`, Content-Disposition with filename

## Implementation Notes

- Install `weasyprint` and add to `requirements.txt` (may need GTK/msys2 on Windows)
- Render HTML template with inline CSS, convert via `weasyprint.HTML(string=html).write_pdf()`
- Use existing executive summary data model
- Template in `api/export_templates/report.html`
