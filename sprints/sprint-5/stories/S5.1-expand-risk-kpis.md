# S5.1 — Expand Risk KPIs

## Description

Add new risk-control KPIs to the KPI calculator: blocked critical count, aging critical (>14d), SLA-close indicators (issues approaching resolution SLA breach).

## Acceptance Criteria

- [ ] `blocked_critical_open` — count of critical/blocker issues with status ≠ Done that are flagged as blocked
- [ ] `aging_critical_open` — count of critical issues open > 14 days
- [ ] `sla_at_risk` — count of unresolved issues where resolution_time_days / avg_resolution_days > 0.8 (80% of SLA consumed)
- [ ] All three KPIs stored in `KPIResult` with category "risk_control"
- [ ] Tests for each new KPI with known data

## Implementation Notes

- Add to `KPICalculator._risk_control()` in `calculator.py`
- Use existing `fact_issue` columns: `priority`, `status_category`, `age_days`, `resolution_time_days`
- Blocked detection: check labels JSON for "blocked" or check status name contains "Blocked"
