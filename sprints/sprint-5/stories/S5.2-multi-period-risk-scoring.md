# S5.2 — Multi-Period Risk Scoring

## Description

The risk scorer currently only computes risk for the "1m" period. Extend
it to compute risk scores for 1-week, 1-month, and 3-month windows.

## Acceptance Criteria

- [ ] Risk computed for 1w, 1m, 3m periods
- [ ] Each period has its own composite risk score
- [ ] 1w = short-term risk (incidents, blockers)
- [ ] 1m = medium-term (trends, aging)
- [ ] 3m = strategic (capacity, release risk)
- [ ] API accepts optional `period` parameter

## Implementation Notes

- Window size sets the lookback for issue queries
- 1w: lookback 7 days, focus on recent blockers
- 3m: lookback 90 days, focus on systemic issues

## Files Changed

- `backend/risk_engine/scorer.py` — compute for 1w, 1m, 3m
- `backend/config.py` — add risk period configs
