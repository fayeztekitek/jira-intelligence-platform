# S4.3 — Release KPIs

## Description

Compute KPIs for fix versions (releases): version completion percentage,
scope increase, delayed issues, and version readiness.

## Acceptance Criteria

- [ ] Version completion = resolved issues / total issues in version
- [ ] Scope increase = issues added after version creation date
- [ ] Delayed issues = issues unresolved past version release date
- [ ] Version readiness = completion % - delay penalty
- [ ] All versions listed with progress bars

## Implementation Notes

- Use `FactIssue.fix_version_ids` JSON field
- Map fix version IDs to names and dates from `DimVersion` (or Jira API)
- Version release date from Jira API `/rest/api/3/version/{id}`
