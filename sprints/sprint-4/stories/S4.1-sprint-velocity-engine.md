# S4.1 — Sprint Velocity Engine

## Description

Create a dedicated sprint velocity module that computes:
- **Commitment**: total story points at sprint start
- **Completed**: points resolved by sprint end
- **Carry-over**: points moved to next sprint
- **Predictability**: completed / commitment ratio
- **Velocity trend**: rolling average over last N sprints

## Acceptance Criteria

- [ ] Sprint identified from `FactIssue.sprint_ids` JSON field
- [ ] Commitment = sum of story points for issues in sprint
- [ ] Completed = issues resolved before sprint end date
- [ ] Carry-over = incomplete issues still in next sprint
- [ ] Predictability = completed points / commitment points (0–1)
- [ ] Velocity = moving average of completed points over last 3 sprints
- [ ] Handles sprints with no story points (time-based tracking)

## Implementation Notes

- Parse sprint JSON from customfield: `[{"id": 1, "name": "Sprint 1", "state": "active", ...}]`
- Use `max(end_date)` from sprint customfield for sprint boundaries
- Store results in new `SprintVelocity` table or `KpiResult` with category "sprint"
