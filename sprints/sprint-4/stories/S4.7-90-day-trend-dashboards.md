# S4.7 — 90-Day Trend Dashboards

## Description

Create trend dashboards showing 90 days of history for all 6 KPI families:
Delivery, Sprint, Quality, Risk, Productivity, Release. Each family gets
its own tab with line charts.

## Acceptance Criteria

- [ ] 6 KPI family tabs: Delivery, Sprint, Quality, Risk, Productivity, Release
- [ ] Each tab shows 3-4 line charts over 90-day window
- [ ] Charts use ECharts with consistent color scheme
- [ ] Legend, tooltip, and zoom slider on every chart
- [ ] Tab persists in URL hash (bookmarkable)

## KPI Families

| Family | Charts |
|--------|--------|
| Delivery | Created vs Resolved, Lead Time, Cycle Time, Throughput |
| Sprint | Velocity, Predictability, Scope Change, Carry-over |
| Quality | Bug Rate, Bug Resolution Time, Reopen Rate |
| Risk | Composite Risk, Blocked Count, Aging Issues |
| Productivity | Points per Dev, Issues per Dev, Resolution Rate |
| Release | Completion %, Scope Increase, Delay Rate |
