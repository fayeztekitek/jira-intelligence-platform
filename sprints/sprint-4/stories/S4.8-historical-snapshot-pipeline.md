# S4.8 — Historical Snapshot Pipeline

## Description

Enhance the daily snapshot job to write complete snapshots of all KPI
and risk data for every project, enabling historical trend queries.

## Acceptance Criteria

- [ ] Daily job computes snapshots for ALL projects (not just active)
- [ ] Snapshot includes: KPI values, risk scores, issue counts
- [ ] Backfill capability: compute snapshots for past 90 days
- [ ] Idempotent: running twice for same day overwrites, not duplicates
- [ ] Snapshot data queryable via `/api/kpi/history?days=90`

## Implementation Notes

- Same pipeline as periodic KPI computation, but run for all projects
- Backfill: iterate day by day from 90 days ago to yesterday
- Use `UPSERT` on date+projectId composite key

## Files Changed

- `backend/scheduler/jobs.py` — enhanced snapshot job
- `backend/ingestion/snapshot_writer.py` — backfill and idempotency
