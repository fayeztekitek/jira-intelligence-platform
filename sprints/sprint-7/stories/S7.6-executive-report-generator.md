# S7.6 — Executive Report Generator

## Description

Generate structured executive reports with 3 sections: executive summary,
risk assessment, and recommended actions. Reports can be requested via
the AI chat or generated on a schedule.

## Acceptance Criteria

- [ ] "Give me an executive summary for [project]" returns 3-section report
- [ ] Section 1: Summary — 2-3 sentences on overall health (KPI highlights)
- [ ] Section 2: Risks — top 3 risks with scores and context
- [ ] Section 3: Actions — 3-5 recommended actions with priority
- [ ] Report is markdown-formatted with headers and bullet lists
- [ ] Schedule: weekly report generation for all projects (configurable)

## Implementation Notes

- Uses same tool data as recommendations engine
- LLM formats into structured narrative
- Weekly schedule via APScheduler job
