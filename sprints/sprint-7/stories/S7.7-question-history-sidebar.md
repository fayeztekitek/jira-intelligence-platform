# S7.7 — Question History Sidebar

## Description

Add a collapsible sidebar showing recent questions with re-ask and
pin-to-favorites functionality, persisted in localStorage.

## Acceptance Criteria

- [ ] Sidebar shows last 50 questions (most recent first)
- [ ] Click a past question to re-ask it
- [ ] Star icon to pin/unpin favorite questions
- [ ] Pinned questions section at top of sidebar
- [ ] Persist across sessions (localStorage)
- [ ] Clear history button with confirmation
- [ ] Sidebar collapsible (hamburger icon on mobile)

## Implementation Notes

- Store questions as `[{id, text, timestamp, pinned}]` in localStorage
- Max 50 entries, oldest dropped when limit reached
- Clicking a past question calls the same `/api/ai/ask` endpoint
