# S7.3 — French Language Support

## Description

Add bilingual support to the AI agent: detect French questions, answer in
French, and maintain separate prompt templates for each language.

## Acceptance Criteria

- [ ] Language detection via LLM or heuristic (first 3 words check)
- [ ] French system prompt: "Vous êtes un assistant d'analyse JIRA..."
- [ ] All mode templates (executive/technical/operational) translated to French
- [ ] Source citations in French: "[Source: KPI livraison pour projet X]"
- [ ] Tool data presented with French labels ("Projet", "Vélocité", etc.)
- [ ] Mixed language question: answer in the language of the question
- [ ] Fallback to English if language cannot be determined

## Implementation Notes

- Detect language: check for French stop words (le, la, les, des, pour, quel, quels, etc.)
- French templates in `prompts_fr.py` or a `locales/` directory
- Add high-value French translations: delivery=livraison, risk=risque, sprint=sprint
