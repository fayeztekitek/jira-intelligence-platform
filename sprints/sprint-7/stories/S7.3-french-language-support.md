# S7.3 — French Language Support

## Description

Add bilingual support to the AI agent: detect French questions, answer in
French, and maintain separate prompt templates for each language.

## Acceptance Criteria

- [ ] Language detection via LLM or heuristic (first 3 words check)
- [ ] French system prompt: "Vous êtes un assistant d'analyse JIRA..."
- [ ] All mode templates (executive/technical/operational) translated to French
- [ ] Source citations in French: "[Source: KPI livraison pour projet X]"
- [ ] Tool data presented with French labels ("Projet", "Vélocité", etc.)
- [ ] Mixed language question: answer in the language of the question
- [ ] Fallback to English if language cannot be determined

## Implementation Notes

- Detect language via `detect_language()` using French stop words (35+ words) and project keywords
- French templates defined in `prompts.py` alongside English: SYSTEM_PROMPT_FR, EXECUTIVE_TEMPLATE_FR, TECHNICAL_TEMPLATE_FR, OPERATIONAL_TEMPLATE_FR, AMBIGUITY_TEMPLATE_FR, FALLBACK_TEMPLATE_FR, SUGGESTIONS_TEMPLATE_FR, STATIC_SUGGESTIONS_FR
- Label translation via `FRENCH_LABELS` dict (40+ terms) and `translate_labels()` function
- Language detection in `agent.py` `_detect_language()` method called at top of `ask()`
- All prompt helpers (`system_prompt`, `mode_prompt`, `ambiguity_prompt`, `fallback_prompt`) accept `lang='en'|'fr'`
- French static suggestions in `STATIC_SUGGESTIONS_FR`
- `off_topic_msg` and `no_access_msg` bilingual dicts in `agent.py`

- `backend/ai_agent/prompts.py` — add French templates
- `backend/ai_agent/agent.py` — language detection and routing
