# S7.8 — Token Usage Tracking

## Description

Track LLM token usage per request and per user. Store aggregated metrics
for cost estimation and monitoring.

## Acceptance Criteria

- [ ] Each `/api/ai/ask` call logs: prompt_tokens, completion_tokens, total_tokens
- [ ] Usage stored in `AiUsage` table: user_id, timestamp, tokens, cost_estimate
- [ ] Cost estimate: $0.01/1K prompt tokens, $0.03/1K completion tokens (GPT-4 rates)
- [ ] GET /api/ai/usage returns usage stats for current user
- [ ] Admin can see all users' usage
- [ ] Usage reported in response: `{"tokens_used": 450, "cost_estimate": 0.005}`

## Implementation Notes

- Extract token counts from LLM API response
- Store in-memory aggregator + DB persistence
- Reset monthly for billing period
