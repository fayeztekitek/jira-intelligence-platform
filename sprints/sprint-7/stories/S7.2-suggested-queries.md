# S7.2 — Suggested Queries

## Description

Generate dynamic suggested question chips based on the current project
context. Suggestions adapt based on what data is available.

## Acceptance Criteria

- [ ] 4-6 suggested queries shown as clickable chips below input
- [ ] Suggestions context-aware: "Compare [project] with..." when project selected
- [ ] Clicking a chip populates the input and sends the question
- [ ] Suggestions refresh after each answer (context may change)
- [ ] Fallback suggestions when no context: "What can you tell me about?"

## Implementation Notes

- Two-tier: LLM-based suggestions (if api key configured) or static fallback
- Static suggestions are context-aware: default, project, comparison, risk, executive
- French suggestions via STATIC_SUGGESTIONS_FR when French detected
- Frontend calls `/api/ai/suggest` POST with context object
- Suggestions refresh after each answer via refreshKey prop
