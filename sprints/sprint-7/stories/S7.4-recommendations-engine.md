# S7.4 — Recommendations Engine

## Description

Add an auto-generated recommendations feature that produces 3-5 actionable
recommendations per project based on current KPI and risk data.

## Acceptance Criteria

- [ ] `GET /api/ai/recommendations?project_id=X` returns 3-5 items
- [ ] Recommendations are data-driven (not template-based)
- [ ] Each has: title, description, priority (high/medium/low), impact area
- [ ] Categories: delivery risk, quality improvement, process optimization, capacity
- [ ] Examples: "Critical blocker on PROJ-123 needs attention (blocked 14 days)"
- [ ] Recommendations refresh daily (or on demand)
- [ ] Stored in DB with expiry date

## Implementation Notes

- Rule-based generation engine in `tools.py` with `_scan_kpis()`, `_scan_risk()`, `_scan_issues()`
- 9 rules in `RECOMMENDATION_RULES` list spanning KPIs, risk, and issue scans
- Each recommendation has: title, description, priority (high/medium/low), impact_area
- Impact areas: delivery_risk, quality_improvement, process_optimization, capacity
- Deduplication by title, sorted by priority (high first), max 8 recommendations
- `GET /api/ai/recommendations?project_id=X` endpoint added to routes.py
- Agent also uses this via `get_recommendations` tool in conversation flow
