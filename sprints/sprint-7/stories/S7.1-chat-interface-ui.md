# S7.1 — Chat Interface UI

## Description

Build the interactive chat interface with message bubbles, typing indicator,
and suggested query chips.

## Acceptance Criteria

- [ ] Chat panel with scrollable message history
- [ ] User messages (right-aligned, blue) and bot messages (left-aligned, white)
- [ ] Typing indicator animation while AI is responding
- [ ] Markdown rendering in bot messages (tables, lists, bold)
- [ ] Input field with send button and Enter-to-send
- [ ] Suggested query chips below input
- [ ] Auto-scroll to bottom on new messages
- [ ] Mobile-responsive layout

## Implementation Notes

- Vite+React set up in `frontend/ai-chat/` with React 19
- `react-markdown` for markdown rendering (tables, lists, code)
- CSS-only typing indicator (three bouncing dots with `@keyframes pulse`)
- Messages stored in component state (no global store)
- Auth token read from `localStorage` (same key as the main HTML app)
- Built to `frontend/ai-chat/dist/`, served by FastAPI at `/ai/` route
- Dev mode uses Vite proxy to forward `/api` to `localhost:8000`
- Fixed 5 sprint-6 story frontmatter statuses from `in-progress` to `completed`
