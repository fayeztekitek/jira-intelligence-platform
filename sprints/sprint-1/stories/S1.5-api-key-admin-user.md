# S1.5 — API Key Admin User

## Description

Provide a deterministic admin user derived from the application's
`APP_SECRET_KEY`. This allows programmatic access without requiring
a user database or registration flow during MVP.

## Acceptance Criteria

- [x] Admin API key = `sha256("admin:" + APP_SECRET_KEY)[:32]`
- [x] Key works with `X-API-Key` header and Bearer token login
- [x] Admin user has `role="admin"` in token claims
- [x] Non-admin tokens can also be issued (for future role-based access)

## Implementation Notes

- Store hashed key in memory at startup
- The admin user is virtual — no DB row needed

## Files Changed

- `backend/api/auth.py` — added admin key derivation and validation
