# S1.3 — Frontend Auth

## Description

Add authentication flow to the single-page HTML frontend: token storage,
auto-re-auth on 401, and auth headers on all API requests.

## Acceptance Criteria

- [x] Login form shown on first visit (when no token stored)
- [x] API key input field with "Login" button
- [x] Token stored in `localStorage`
- [x] All `fetch()` calls include `Authorization: Bearer <token>` header
- [x] On 401 response, automatically clear token and show login form
- [x] Auto re-auth: retry request after successful re-login

## Implementation Notes

- Use a centralized `apiFetch()` wrapper around `fetch()`
- Token expiry handled by checking `exp` claim client-side

## Files Changed

- `frontend/index.html` — added auth flow, apiFetch wrapper
