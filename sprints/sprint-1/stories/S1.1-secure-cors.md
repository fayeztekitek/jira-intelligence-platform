# S1.1 — Secure CORS

## Description

Replace the wildcard CORS origin `["*"]` with an environment-controlled
`ALLOWED_ORIGINS` configuration. In development the wildcard is acceptable,
but in production only explicitly listed origins must be allowed.

## Acceptance Criteria

- [x] `ALLOWED_ORIGINS` env var parsed into a list of strings
- [x] Wildcard `["*"]` only allowed when `ENVIRONMENT=development`
- [x] Production with no `ALLOWED_ORIGINS` set logs a warning and rejects all
- [x] CORS middleware in `main.py` reads from `config.ALLOWED_ORIGINS`

## Implementation Notes

- Parse comma-separated values in `config.py`
- Pass directly to `CORSMiddleware(allow_origins=...)`
- Add `ALLOWED_ORIGINS` to `.env.example`

- `backend/config.py` — added `ALLOWED_ORIGINS` property
- `backend/main.py` — pass to CORSMiddleware
- `.env.example` — added example entry
