# S1.2 — JWT Auth Module

## Description

Create a reusable authentication module supporting two mechanisms:

1. **Bearer JWT token** — short-lived token from `/api/auth/login`
2. **X-API-Key header** — long-lived key derived from `APP_SECRET_KEY`

## Acceptance Criteria

- [x] `POST /api/auth/login` returns `{"access_token": "...", "token_type": "bearer"}`
- [x] JWT tokens expire after `ACCESS_TOKEN_EXPIRE_MINUTES` (default 30)
- [x] `require_auth` FastAPI dependency validates Bearer or X-API-Key
- [x] `require_admin` dependency checks admin flag
- [x] Admin user derived deterministically from `APP_SECRET_KEY`
- [x] Invalid/expired tokens return 401 with descriptive error

## Implementation Notes

- Use `python-jose` for JWT encode/decode
- Admin user email: `admin@<hashed-hostname>.local`
- API key = `sha256("admin:" + APP_SECRET_KEY)[:32]`
