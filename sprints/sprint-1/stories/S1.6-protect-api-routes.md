# S1.6 — Protect All API Routes

## Description

Apply the `require_auth` dependency to all `/api/*` endpoints so that
unauthenticated requests are rejected with 401.

## Acceptance Criteria

- [x] All existing GET/POST endpoints use `AuthDep` or `AdminDep`
- [x] Login and docs endpoints remain public
- [x] Unauthenticated requests receive `{"detail": "Not authenticated"}`
- [x] Admin-only endpoints return 403 for non-admin tokens

## Implementation Notes

- Use FastAPI `Depends(require_auth)` on each route
- Admin endpoints use `Depends(require_admin)`

## Files Changed

- `backend/api/routes.py` — added auth dependency to all 12 endpoints
