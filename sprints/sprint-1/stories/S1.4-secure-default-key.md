# S1.4 — Secure Default Key Enforcement

## Description

Warn or block the application from running in production with the default
`APP_SECRET_KEY`. The default key is well-known ("change-me-in-production")
and would compromise all security.

## Acceptance Criteria

- [x] Default key detected and compared on startup
- [x] In production: application refuses to start with default key
- [x] In development: warning logged but startup proceeds

## Implementation Notes

- Check `APP_SECRET_KEY == "change-me-in-production"` in `config.py`
- Use `logger.warning` in dev, `sys.exit(1)` in prod

## Files Changed

- `backend/config.py` — add validation after settings load
- `backend/main.py` — call validation on startup
