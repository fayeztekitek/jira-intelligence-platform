# S6.7 — AI Chat API Endpoint

## Description

Create `POST /api/ai/ask` endpoint that accepts a user question and returns
an AI-generated answer with source citations.

## Acceptance Criteria

- [ ] Request: `{"question": "...", "mode": "executive|technical|operational", "project_id": "..."}`
- [ ] Response: `{"answer": "...", "sources": [...], "mode": "...", "tokens_used": N}`
- [ ] Supports streaming via SSE (`Accept: text/event-stream`)
- [ ] Authenticated (requires valid JWT/API key)
- [ ] Rate-limited: 20 requests per minute per user
- [ ] Logged to audit log with question and response length

## Implementation Notes

- SSE streaming with `EventSourceResponse` or custom async generator
- Non-streaming returns full JSON response
- Rate limiting via in-memory counter (per user ID claim)
