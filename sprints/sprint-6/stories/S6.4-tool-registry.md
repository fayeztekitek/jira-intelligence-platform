# S6.4 — Tool Registry (8 Tools)

## Description

Implement the tool registry with 8 tools that the agent can call:

1. `get_project_kpis` — delivery, quality, risk KPIs for a project
2. `get_risk_scores` — composite + dimension risk scores
3. `search_issues` — search issues by JQL-like filters
4. `get_exec_summary` — executive summary with headline KPIs
5. `compare_projects` — side-by-side KPI comparison
6. `get_sprint_analysis` — sprint velocity, burndown, scope change
7. `get_trend` — time-series data for any KPI
8. `get_recommendations` — auto-generated action items

## Acceptance Criteria

- [ ] Each tool has a name, description, parameter schema, and handler
- [ ] Tools return structured dicts ready for LLM formatting
- [ ] Tools validate parameters before executing
- [ ] Tool execution timed out after 30s
- [ ] Tool errors returned as structured error dicts
- [ ] Tool registry discoverable by orchestrator via `list_tools()`

## Implementation Notes

- Each tool is a Python function decorated with `@tool(name, description)`
- Parameter schema uses Pydantic models for validation
- Tools call existing API/storage layer functions
