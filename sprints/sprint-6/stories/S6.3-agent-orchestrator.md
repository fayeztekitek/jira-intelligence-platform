# S6.3 — Agent Orchestrator

## Description

Build the core agent orchestrator that: classifies user intent → dispatches
to the correct tool → formats response → applies guardrails.

## Acceptance Criteria

- [x] Intent classification: executive, technical, operational, comparison, historical (keyword-based)
- [x] Tool dispatch based on intent + parameters extracted from question text
- [x] Response generation: structured natural-language formatting per tool type
- [x] Ambiguity resolution: keyword-weighted scoring when multiple tools match same intent
- [x] Context window: retains last 10 exchanges (configurable via `agent_context_size`)
- [x] All tool calls logged with latency (structlog, milliseconds)

## Implementation Notes

- Use LLM function-calling API (OpenAI / Claude)
- Intent classification via prompt: "Classify this question into one of: ..."
- Tool dispatch: extract parameters as JSON, call tool function
- Response: LLM takes [tool result] + [original question] and writes answer
