# S6.3 — Agent Orchestrator

## Description

Build the core agent orchestrator that: classifies user intent → dispatches
to the correct tool → formats response → applies guardrails.

## Acceptance Criteria

- [ ] Intent classification: executive, technical, operational, comparison, historical
- [ ] Tool dispatch based on intent + parameters extracted from prompt
- [ ] Response generation: format tool output into natural language
- [ ] Ambiguity detection: if multiple tools match, ask clarifying question
- [ ] Context window: maintains last 10 exchanges for follow-up questions
- [ ] Streaming response support (SSE for chat UI)
- [ ] All tool calls logged with latency

## Implementation Notes

- Use LLM function-calling API (OpenAI / Claude)
- Intent classification via prompt: "Classify this question into one of: ..."
- Tool dispatch: extract parameters as JSON, call tool function
- Response: LLM takes [tool result] + [original question] and writes answer
