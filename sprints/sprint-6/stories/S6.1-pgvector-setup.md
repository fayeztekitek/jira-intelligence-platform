# S6.1 — pgvector Setup

## Description

Enable the pgvector PostgreSQL extension and add a vector column for
storing embeddings on relevant tables.

## Acceptance Criteria

- [ ] `CREATE EXTENSION vector` migration
- [ ] `embedding vector(384)` column on `kpi_result` table
- [ ] `embedding vector(384)` column on `fact_issue` table
- [ ] `embedding vector(384)` column on `dim_project` table
- [ ] HNSW index on each embedding column for fast similarity search
- [ ] `alembic upgrade head` works with PostgreSQL (skips on SQLite)

## Implementation Notes

- Use 384-dim embeddings (all-MiniLM-L6-v2 is a good default)
- SQLite fallback: skip vector columns, log warning
- HNSW index: `CREATE INDEX ON kpi_result USING hnsw (embedding vector_cosine_ops)`
