# S6.1 — pgvector Setup

## Description

Enable the pgvector PostgreSQL extension and add a vector column for
storing embeddings on relevant tables.

## Acceptance Criteria

- [x] `CREATE EXTENSION vector` on PostgreSQL (skipped on SQLite)
- [x] `embedding` column (Text / vector(384)) on `kpi_result`, `fact_issue`, `dim_project`
- [x] HNSW indexes on PostgreSQL only
- [x] `alembic upgrade head` works on both PostgreSQL and SQLite
- [x] `ENABLE_PGVECTOR` config flag

## Implementation Notes

- Use 384-dim embeddings (all-MiniLM-L6-v2 is a good default)
- SQLite fallback: skip vector columns, log warning
- HNSW index: `CREATE INDEX ON kpi_result USING hnsw (embedding vector_cosine_ops)`
