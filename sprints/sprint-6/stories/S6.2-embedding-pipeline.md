# S6.2 — Embedding Pipeline

## Description

Create a pipeline that generates and stores embeddings for KPI definitions,
issue summaries, and project metadata using sentence-transformers.

## Acceptance Criteria

- [x] Embedding generation for: KPI name + formula + interpretation, issue summary + key, project name + description
- [x] Batch processing (size 32, configurable via `EMBEDDING_BATCH_SIZE`)
- [x] Incremental: only embed records with NULL `embedding`
- [x] Uses all-MiniLM-L6-v2 model (384-dim, CPU-friendly)
- [x] Embedding stored as JSON float array in Text column (portable across pgvector/SQLite)
- [x] Configurable model via env var `EMBEDDING_MODEL`
- [x] Pipeline trigger: `EmbeddingPipeline.run_incremental()` / `.run_full()`
- [x] Scheduled daily at 03:30 UTC (after KPI calculation)

## Implementation Notes

- Use `sentence-transformers` library
- Process in batches of 32 for efficiency
- Cache model in memory after first load
