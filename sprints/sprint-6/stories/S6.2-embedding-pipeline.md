# S6.2 — Embedding Pipeline

## Description

Create a pipeline that generates and stores embeddings for KPI definitions,
issue summaries, and project metadata using sentence-transformers.

## Acceptance Criteria

- [ ] Embedding generation for: KPI name + description, issue summary + key, project name + description
- [ ] Batch processing (not one by one)
- [ ] Incremental: only embed new/updated records
- [ ] Uses all-MiniLM-L6-v2 model (384-dim, CPU-friendly)
- [ ] Embedding stored in respective pgvector columns
- [ ] Configurable model via env var `EMBEDDING_MODEL`
- [ ] Pipeline can be triggered manually or via scheduler

## Implementation Notes

- Use `sentence-transformers` library
- Process in batches of 32 for efficiency
- Cache model in memory after first load
