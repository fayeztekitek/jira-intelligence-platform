# S6.6 — Guardrails

## Description

Implement agent guardrails for:
- **Hallucination prevention**: reject answers not supported by tool data
- **Source citation**: every claim must cite its source tool
- **Permission check**: verify user has access to requested project
- **Ambiguity detection**: ask for clarification when intent is unclear

## Acceptance Criteria

- [x] Output validation: source citation regex enforcement
- [x] Source citation required: `enforce_source_citation()` appends if missing
- [x] Permission guard: `check_permission()` verifies project access
- [x] Ambiguity detection: `detect_ambiguity()` returns interpretations when multiple tools match
- [x] PII redaction: `strip_pii()` removes emails and user IDs
- [x] Content safety: `is_off_topic()` rejects harmful/off-topic questions

## Implementation Notes

- Post-processing LLM call: verify response against tool data
- Permission check via `UserSession.projects` from JWT
- Ambiguity threshold: number of matching tools > 1 → ask
