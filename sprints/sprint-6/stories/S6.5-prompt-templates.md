# S6.5 — Prompt Templates

## Description

Design and implement prompt templates for the AI agent including:
system prompt, mode templates (executive/technical/operational),
and ambiguity handling prompts.

## Acceptance Criteria

- [x] System prompt: agent identity, capabilities, constraints
- [x] Executive mode: concise, high-level, recommendation-focused
- [x] Technical mode: detailed, data-focused, with numbers and precision
- [x] Operational mode: action-oriented, task-focused
- [x] Ambiguity handler: "I found multiple interpretations..."
- [x] Fallback prompt: "I don't have enough data to answer that"
- [x] Source citation format: inline `[Source: ...]`

## Implementation Notes

- Templates use Jinja2 with variables: `{{project_name}}`, `{{kpi_data}}`
- Mode selected by intent classifier or explicit user request
- Source citations use markdown-style brackets
