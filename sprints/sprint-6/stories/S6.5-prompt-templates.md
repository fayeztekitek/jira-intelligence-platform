# S6.5 — Prompt Templates

## Description

Design and implement prompt templates for the AI agent including:
system prompt, mode templates (executive/technical/operational),
and ambiguity handling prompts.

## Acceptance Criteria

- [ ] System prompt: agent identity, capabilities, constraints
- [ ] Executive mode: concise, high-level, recommendation-focused
- [ ] Technical mode: detailed, data-focused, with numbers and SQL-like precision
- [ ] Operational mode: action-oriented, task-focused
- [ ] Ambiguity handler: "I found multiple interpretations..."
- [ ] Fallback prompt: "I don't have enough data to answer that"
- [ ] Source citation format: inline `[Source: KPI delivery for project X]`

## Implementation Notes

- Templates use Jinja2 with variables: `{{project_name}}`, `{{kpi_data}}`
- Mode selected by intent classifier or explicit user request
- Source citations use markdown-style brackets
